Assistance

Une question, un problème ? Écris-nous à support@bokkapp.com en indiquant ton numéro de téléphone et ce qui se passe. On te répond rapidement.

Je ne reçois pas le code par SMS

Vérifie le numéro (9 chiffres, sans le +221), attends une minute, puis touche « Renvoyer le code ». Si rien n’arrive, écris-nous.

J’ai changé de téléphone

Installe Bokk, connecte-toi avec le même numéro (ou le même compte Google ou Apple), puis tape ton code secret : tu retrouves tous tes groupes. Depuis ton nouveau téléphone, tu peux déconnecter l’ancien (Profil, Sécurité).

J’ai tapé trop de codes secrets faux

Après 10 codes faux en une journée, Bokk ferme la session pour protéger ton compte. Reconnecte-toi avec ton numéro, puis tape ton code secret. Si tu l’as oublié, écris-nous.

Un membre dit qu’il a payé, mais je n’ai rien reçu

Dans le versement en attente, touche « Signaler un écart ». Le versement n’est pas compté, et vous pouvez régler la question entre vous.
